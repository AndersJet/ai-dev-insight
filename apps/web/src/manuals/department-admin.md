**一级部门管理员操作手册：管理授权部门的成员与采纳进度**

你只管理被授权的一级部门；如果有多个授权部门，通过侧栏切换。你可以查看范围内的人员统计、维护成员，并查看本人详细使用记录。


### 一、组织分析：确认当前部门

进入“组织分析”后先核对侧栏选中的部门。查看本部门注册、待采纳、已采纳和累计采纳率，再结合日期范围观察实际使用变化。切换部门时同时确认页面标题和范围，避免将一个部门的结果当成全部 组织 的结果。

人员统计用于识别采纳进度和使用变化，不提供其他人员会话原文。多个授权部门分别按可用入口查看，不能通过改地址访问未授权部门。

### 二、成员管理

进入“组织管理”，在当前授权部门新增、导入或维护成员。导入前下载模板，填入所需资料，上传后确认预览再提交；遇到跨部门冲突，按授权范围协调，不把同邮箱人员复制成新身份。

对未分配且可关联的人员使用已有身份关联流程。移出部门后保留账号与历史记录；本角色没有跨部门调动入口，需要调动或取消调动计划时联系 组织管理员或系统管理员。

本角色不配置全事业部一级部门，也不授予系统管理员角色；账号停用、逻辑删除、采集凭据撤销、数据清理等系统级操作不在此页提供。

### 三、协助员工完成接入

打开待采纳名单，向员工说明注册不等于已经安装。引导其安装平台分发的 Trae 插件，在插件内登录本人账号、完成自动安装与全局 Hooks 启用，再通过正常 Trae 对话产生上报。网页“采集安装”用于查看本人 API 码与来源记录。

查看接入结果时依据已采纳和最近成功上报；不要仅凭员工已下载文件判定完成。需要账号恢复或凭据问题处理时，联系系统管理员。

### 四、我的空间

使用本人的概览、Token 使用分析和会话详情复盘自己的使用；本人采集安装、密码维护与员工流程一致。管理部门不改变个人入口的人员身份。

### 五、常见问题

- 看不到另一个部门：检查是否获得该部门授权。
- 看得到某成员统计，却打不开会话原文：这是权限边界，非页面故障。
- 需要跨部门调动：联系 组织管理员或系统管理员完成。
- 某人停用后仍在累计分母：这是已确认的统计规则，不是需要手工排除的数据。
