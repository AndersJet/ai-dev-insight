**组织管理员操作手册：推进各部门采纳与组织维护**

你可以查看 组织 范围的组织和人员使用统计，维护一级部门与成员。个人会话原文和详细执行内容仍只查看本人；账号停用和系统运营由系统管理员负责。


### 一、组织分析：从事业部到部门

进入“组织分析”查看 组织概览，再从侧栏切换一级部门。先看注册和采纳进度，再选择期间查看真实使用变化；用相同时间与范围比较部门，避免将采纳率当作当期活跃率。

打开人员统计查看聚合情况。管理统计权限不包含他人的会话原文，不在此手册提供读取他人提示、回答或原始事件的路径。

### 二、组织管理：维护部门与成员

进入“组织管理”，查看全部部门成员或指定部门；通过“部门配置”新增、重命名或删除空部门，并配置部门管理员。需要关联官方部门时，先核对页面给出的对应关系再保存，避免把官方数据关联误当成员调岗。

新增/导入成员时使用当前模板，上传后先检查预览结果，处理邮箱重复、部门冲突等提示再提交。

已有账号需要纳入部门时，使用关联已有人员能力，保留原身份；跨部门调动按页面确认生效时间，尚未生效的计划可按对应入口取消。移出部门只调整成员关系，不等于删除账号或清理历史使用。

### 三、推进待采纳人员

从组织概览或成员列表进入待采纳名单，指导员工安装平台分发的 Trae 插件，在插件内注册或登录本人账号，完成自动安装与全局 Hooks 启用，再通过正常对话验证真实上报。网页“采集安装”只展示本人 API 码与来源记录；你可以查看职责范围内的接入进度，不代领他人凭据。

看到停用状态时，核对业务背景并联系系统管理员处理；能查看状态不代表可以恢复账号。已停用、已删除人员仍保留在累计采纳统计中，没有人工排除人员的操作。

### 四、我的空间

在“我的空间”查看本人概览、本人的 Token 使用分析和会话详情，查看自己的采集来源，实际安装与修复在插件完成。本人模型确认只表达个人声明，不能替代官方用量记录。

### 五、常见问题

- 为什么有部门统计却看不到员工会话正文？统计管理和正文阅读是不同权限。
- 为什么找不到账号停用或系统运营？这些操作属于系统管理员。
- 为什么待采纳人员仍在分母？全部注册人员都是推广目标，不能通过排除提高采纳率。
- 为什么调岗前数据还在原部门？历史使用按当时归属保留。
