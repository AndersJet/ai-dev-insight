**普通员工操作手册：完成个人接入并查看自己的使用记录**

你可以通过“我的空间”查看本人使用概览、Token 使用分析和会话详情，管理个人采集安装。首次使用建议先完成安装，再查看采纳和使用数据。


### 一、采集安装

在 Trae CN 安装平台分发的 AI Dev Insight Token分析助手 VSIX，在原生扩展设置填写平台 Web 根地址，然后打开 ADI 侧栏，注册或登录本人平台账号。插件会自动检查并安装个人 Hooks；无需另装 Node。

文件就绪后，点击“查看启用步骤”，在 Trae“设置 → Hooks → 全局”启用“已配置的 Hooks”，核对运行方式，必要时自行重启。完成设置后可点击“确认已完成启用设置”，再新建正常对话，通过实际 Hook 日志与保存记录验证。该确认和文件就绪都不等于采集成功；安装冲突请使用插件“检查／修复 Hooks”，不要覆盖第三方或手改配置。

网页“我的空间 → 采集安装”用于显示或复制本人账号共用的 API 码，并查看来源记录。多电脑登录取回同一 API 码，密码变更不影响插件和 Hook 授权。旧网页在线命令和 ZIP 下载入口已退役，请勿共享 API 码或安装材料。

原生扩展设置的 Enabled 同时暂停本机 Git 与 Hook 采集，暂停跨重启保留；退出本机、停用插件或关闭最后窗口会停止采集，其他电脑和历史记录保留。来源登记不表示当前在线，只有正常 Hook 成功保存才确认已采纳。

### 二、我的概览

打开“我的空间”中的个人概览，选择日期范围查看本人实际使用。将采纳状态与期间活跃分开理解：已经采纳，某一周也可能没有新记录。

官方报告的 Token、费用与本地内容估算分别显示。数据缺失不等于零，不将本地估算或模拟结果当作最终账单。

### 三、我的 Token 使用分析

进入“我的Token使用分析”，在会话列表中找到要复盘的记录，打开详情查看执行轨迹、用量与出账、原始事件和会话信息。使用页面提供的分页和筛选定位内容。

如果会话模型渠道需要本人确认，按实际使用情况填写；这是一项可撤销的个人声明，不会生成官方 Token 或费用。计费用量模拟是帮助理解场景的估算，不代表真实扣费。

### 四、密码与账号问题

在“我的空间”左侧进入“修改密码”，填写当前密码、新密码和确认新密码后保存。成功后留在原页，密码字段清空并提示“密码已修改”，可点击“返回我的概览”。首次或临时密码要求更新时，只能改密或退出；保存后继续原目标或完成账号注册。忘记密码或临时密码过期，联系系统管理员按平台流程重置；账号停用或逻辑删除不能通过重复注册绕过。

### 五、常见问题

- 注册后为什么还是待采纳？系统尚未保存你的正常 Hook，继续完成本机安装和上报验证。
- 已采纳为何看不到本周使用？检查所选日期、最近上报和实际采集情况；已采纳不是实时在线状态。
- 为什么没有组织管理等菜单？普通员工使用本人空间，相应管理功能按角色授权。
- HTTP 页面不能复制 API 码怎么办？点击显示 API 码后手动复制，仅在可信位置使用。
- 停用或删除后历史数据还在吗？历史记录和累计采纳事实保留，登录和新采集按账号状态处理。
