# 插件管理的原生 Hook 客户端

员工接入、全局 Hooks 启用、暂停与修复统一见 [安装说明](INSTALL.md)；插件本身的安装与今日概览见 [插件说明](../../trae-plugin/README.md)。网页在线命令和个人 ZIP 下载已退役，原生脚本由插件调用。

## 开发目录

- `native/`：macOS/Windows 员工发行包的来源，无需员工预装 Node。
- `src/`：工程使用的 Node 实现及协议回归参考，不进入员工发行包。
- `test/`：协议、安装所有权、发送期限及原生进程回归。

从仓库根执行 `pnpm client:package` 构建无身份模板；API 在受授权的插件下载时加入本人 Hook 凭据。个人材料、运行状态和恢复证明不属于可清理缓存。

工程/进程测试与真实 Trae 验收分别记录。合成测试通过不表示某个 IDE 或设备已通过安装、采集和升级验收；在目标设备核对当前构建及实际入库结果。
