# 插件管理的个人 Hooks（Windows / macOS，试点版）

员工通过 AI Dev Insight Token分析助手插件接入。网页“我的空间 → 采集安装”用于查看本人账号共用的 API 令牌与来源状态；旧在线安装命令和个人 ZIP 下载入口已经退役。

## 接入与自动安装

1. 在 Trae CN 扩展面板从平台分发的 VSIX 安装插件。
2. 在 Trae 原生扩展设置填写 `adiProjectTracker.webUrl`，只支持 HTTP/HTTPS 根站点。
3. 打开 ADI 侧栏，注册或登录本人平台账号。认证成功前不采集 Git 仓库；插件不保存登录密码。
4. 插件领取本人共用 API 令牌和独立的 Hook 安装材料，自动检查当前用户标准全局目录：macOS `~/.trae-cn`，Windows `%USERPROFILE%\.trae-cn`。无需另装 Node、Python、jq 或 PowerShell 7；不提供项目级或自定义目录入口，Linux 不在支持范围。
5. 完整一致安装保持不变；已知本项目旧版可安全备份升级，第三方 Hook 保留。全局配置文件被删除、清空或所有事件列表均为空时，可通过“重试 Hook 安装”重新创建六类采集条目，并保留本机采集端身份；原有受管文件和凭据仍须通过核验。部分删除、手改、残缺或无法确认的配置停止自动覆盖，由插件显示修复提示。

本材料内的 `adi-installation.json` 是私有 Hook 上报凭据，仅供本人电脑使用。接收地址通过所绑定的 Web 根站点 `/hooks` 转发；支持 HTTP/HTTPS，不忽略证书错误、不跟随重定向。不要共享安装材料、复制本机采集端状态到另一台电脑或发布凭据。

## 首次启用全局 Hooks

文件就绪后，在 Trae“设置 → Hooks”核对全局 Hooks 开关、采集命令来源和运行方式，并确认 IDE 的执行授权；必要时自行重启。插件不会强制重启 IDE 或替用户开启执行权限。系统 Windows PowerShell 和本机编译的私有程序须符合终端策略，策略阻止时按提示联系管理员。

发起正常对话后，在插件及网页核对实际保存证据。文件就绪、IDE 开关已启用和事件成功保存分别表达；下载、安装、HTTP 200 或本地 `status` 都不等于真实采集已完成。Hook 安装失败不阻止已认证的插件 Git 观测。

## 暂停、退出与修复

- 原生扩展设置 `adiProjectTracker.enabled` 暂停或恢复本机插件 Git 与本项目 Hook 两路采集，暂停跨重启保留。
- 退出本机、禁用扩展或关闭最后一个插件窗口会停止采集；异常退出由短租约失效控制。账号永久授权不代表退出 IDE 后继续采集。
- 重新登录取回原账号共用 API 令牌；网页改密不影响插件与 Hook 授权。其他电脑分别绑定，不受本机暂停或退出影响。
- 插件提供“检查／修复 Hooks”入口。未知锁、手改或安装中断冲突会保留现场并提示；不要删不明锁、整份覆盖 hooks.json 或反复运行旧安装器。
- 原生安装脚本是插件调用的内部材料，维护与合成测试使用固定参数和隔离目录；不再作为员工独立安装入口。

## 行为与验证边界

每个 Hook 尽力发送一次，失败静默退出0；不后台重试、不把事件原文保存到本地。程序期限750ms，Trae配置超时2秒。系统进程启动及宿主行为仍需真实 Trae 验收，不承诺零延迟。

macOS 隔离测试覆盖安装、更新、卸载与发送路径；Windows 原生以及真实 Trae 人工问答需在目标环境验收，当前保持试点版。

项目仓库观测由实际 Hook 触发，首次尝试后同一项目最多每5分钟探测一次；只读取本地 Git 配置，不访问远端，也不扫描项目源码。采集端身份保存在 adi-native-collector/project-state，升级和重置凭据沿用；不要将该目录复制到另一台电脑。状态丢失或损坏会建立新实例。缺 Git、探测失败或未确认项目时，正常 Hook 仍尽力上报。

Windows 安装时使用系统 .NET 编译私有的 adi-sender.exe，后续 Hook 的输入处理、项目状态、本地Git和HTTP由该程序执行；不另起PowerShell worker，不在每次对话时编译，不需要员工安装开发工具。企业策略必须允许该本地程序及系统 PowerShell 运行；安装失败应按错误处理，不关闭企业安全策略。750ms是程序内部截止，系统启动成本另计，仍受Trae配置的2秒超时约束；冷启动、完整状态生命周期、进程树及真实Trae仍待目标环境验收。
