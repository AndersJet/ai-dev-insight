# Changelog

## [1.0.0] - 2026-10-20

Initial independent community release under Apache-2.0.

- Connect to an operator-managed AI Dev Insight platform using the community plugin namespace.
- Support account registration/login, plugin credentials, native macOS/Windows Hook materials, Git project observation and personal session analysis.
- Include the Remote SSH workspace helper with the same release version.
- Require explicit configuration for acceptance environments and include project and third-party license materials in both VSIX packages.

Native platform and real IDE compatibility require separate acceptance for the exact build; this release number does not establish untested device coverage.
