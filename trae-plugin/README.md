# AI Dev Insight 分析助手

将 Trae 连接到你自行部署的 AI Dev Insight，查看个人使用概览、历史会话和 Token 能效分析，并管理本机 Hook 与 Git 项目观测。

## 安装与接入

通过 Trae 的“从 VSIX 安装”入口安装主插件，然后在扩展设置中填写 `adiProjectTracker.webUrl`，例如 `http://localhost:4181` 或你部署的 HTTPS 根地址。不要填写容器内部 API 端口或带路径的地址。

在插件内注册或登录本人平台账号。新成员需要选择平台管理员建立的部门；已有账号按平台流程登录，不通过匿名注册覆盖已有身份。

主插件身份为 `ai-dev-insight.adi-project-tracker`。同一使用环境仅启用预期的采集插件；更换扩展身份后需要重新登录，旧扩展的本机凭据不会自动迁入。

## 采集与日常使用

- 按插件指引安装 Hook，并在 Trae 中启用对应设置
- 本机文件就绪、设置已确认和事件已保存分别显示
- Git 观测只针对可信工作区的元数据
- 暂停、恢复和退出登录只影响当前电脑，不替代平台账号管理或历史数据清理
- 安装失败时使用插件的检查/修复入口，保留第三方 Hook 和失败备份

下载成功或 HTTP 请求结束不证明事件已经入库。出现问题时核对平台地址、登录状态、工作区信任、Hook 启用状态及平台最近成功记录。

## 会话与 Token 分析

本人历史会话与分析材料遵守账号范围，管理角色不会扩大插件读取范围。官方用量、估算、观测量和缺失值分别表达。分析材料可能包含真实会话内容，应按组织的数据规则保管。

## Remote SSH

主 VSIX 包含同构建的 Linux 工作区助手。主插件负责界面、登录和平台通信；助手在已授权的 SSH 工作区执行 Hook 与 Git 观测。按侧栏提示安装/检查匹配的助手，并单独完成目标 IDE 的启用与入库验收。

Linux 本地桌面 IDE 与 Linux SSH 工作区是不同运行路径。实际兼容性需要按具体 Trae/系统/插件构建验证。

## 隐私与反馈

Hook 可能记录提示词、回答、工具输入/输出和工作区信息。仅连接你信任且已获准使用的平台。不要把个人安装材料、凭据或原始会话粘贴到公开问题中。
