# Data and privacy

AI Dev Insight is self-hosted. The deployment operator is responsible for explaining collection to participants and controlling access, retention, deletion, and backups.

## Sources

Hook events can include prompts, responses, tool inputs/outputs, timestamps, and working-directory information. Those event bodies may themselves contain code or sensitive content. Git project observation reads repository/workspace metadata and configured remote addresses; it does not scan repository source files or contact Git remotes to collect metadata.

Official usage is a separate, optional provider integration. Reported quantities, estimates, missing values, and local observations are not interchangeable. A user's model declaration does not establish provider billing or actual cost.

## Access

A system administrator can access all members' session content. Organization and department administrators manage their permitted organization scope and statistics, but session content remains self-only. Plugin API authorization is account-bound and self-scoped; management roles do not expand it.

Email is an account identifier. The optional domain allowlist does not verify mailbox ownership or employment.

## Lifecycle

Registration, installation, enabled Hooks, a successful HTTP response, and persisted events are different states. Readiness or a successful download does not prove that collection has been saved.

Pausing or signing out on one computer does not delete history or stop other computers. Resetting a shared collection credential affects the account's other installations. Removing organization membership and deleting usage data are separate operations.

Use the provided cleanup and recovery workflows. Cleanup barriers prevent delayed events or restored backups from republishing cleared data. Keep credential keys and recovery journals protected and consistent with their datasets. See the [deployment guide](../deploy/manual/README.md) and [advanced operations](../deploy/manual/REFERENCE.md).

Do not publish personal packages, real `.env` files, raw events, session bodies, or backup archives in source repositories or bug reports.
